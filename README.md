# Arduino Learning

Arduino projects and exercises: learning embedded systems from scratch, from basic digital output to sensors and motor control.

## Projects

- [**05 - Ultrasonic Distance Meter**](05-ultrasonic-distance-meter): measures distance with an ultrasonic sensor.
- [**04 - DC Motor Pushbutton Control**](04-dc-motor-pushbutton-control): controls DC motor speed and direction with pushbuttons.
- [**03 - SOS Morse Code**](03-sos-morse-code): blinks an LED in the SOS Morse pattern.
- [**02 - Three LED Sequence**](02-three-led-sequence): runs a timed sequence across three LEDs.
- [**01 - LED Blink**](01-led-blink): the classic first project.

## Tools

- Arduino IDE, C++
- Breadboard prototyping
