# SOS Morse Code LED

## Project Description

This project demonstrates how to use an Arduino board to blink an LED in the SOS Morse code pattern. The LED represents the Morse code signal by using short and long flashes.

The purpose of this project is to practice timing control with Arduino and to understand how simple light signals can be used to represent a message.

## Components Used

- Arduino board
- LED
- 220Ω resistor
- Breadboard
- Jumper wires
- USB cable

## How It Works

Morse code uses short and long signals to represent letters. In this project, the LED blinks the SOS pattern:
